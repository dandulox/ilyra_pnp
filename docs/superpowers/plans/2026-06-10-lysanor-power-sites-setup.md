# Lysanor Power Sites Setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Die fünf zentralen Machtorte von `Lysanor` als erste innere Schicht der Hauptstadt im Universum anlegen.

**Architecture:** Die fünf Schauplätze werden als eigenständige `Lysanor`-Ortdateien im Siedlungsbereich angelegt. `Lysanor`, der Siedlungsindex, der Kanon-Index und das Glossar werden ergänzt, damit Hof, Verwaltung, Vorrat und Geheimpolitik sofort navigierbar sind.

**Tech Stack:** Obsidian-Markdown, YAML Frontmatter, Wikilinks, bestehende Universumsstruktur
