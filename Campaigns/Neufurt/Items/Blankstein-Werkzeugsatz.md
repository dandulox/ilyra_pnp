# Blankstein-Werkzeugsatz

## Kurzprofil

Abgenutztes, aber unnatürlich sauber geordnetes Set aus Hammer, Keilen, Messschnur und Öllappen, zurückgelassen am [[Der Blanksteinpfad|Blanksteinpfad]].

## Aktueller Stand

Gültig ab: [[Session 02 - Der Blanksteinpfad]]
Sichtbarkeit: Spielerwissen

Der [[Blankstein-Werkzeugsatz]] wirkt auf den ersten Blick wie hastig abgestellte Schürferausrüstung. Bei näherem Hinsehen ist jedoch jedes Teil mit fast zwanghafter Präzision gereinigt, ausgerichtet und auf Wiederaufnahme vorbereitet, als hätte jemand Ordnung gebraucht, um dem eigenen Kopf zu trauen.

## Bekannter Stand für Spieler

- Das Set deutet darauf hin, dass hier nicht bloß Chaos oder Flucht herrschte.
- Die Pflege der Werkzeuge wirkt übertrieben und unheimlich.
- Wer die Werkzeuge untersucht, erkennt routinierte Arbeitsspuren einer erfahrenen Fahrt.

## DM-Geheimnisse

- Die Ordnung des Sets ist ein frühes, sichtbares Symptom der `Glimmernarben-Vergiftung`.
- Zwischen Lappen und Messschnur kann ein versteckter Hinweis auf [[Halwen Pike]] oder eine Seitenroute liegen.
- Das Set könnte später genutzt werden, um eine Spur der ersten Fahrt eindeutig von fremden Suchern zu unterscheiden.
